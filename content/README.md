# HƯỚNG DẪN DÁN NỘI DUNG VÀO WORDPRESS

## Cách dán

1. Vào **Pages (Trang) → Add New** → đặt tiêu đề → dán nội dung từ file tương ứng.
2. Tiêu đề trang trong WP = dòng `#` đầu tiên; phần còn lại dán vào khối nội dung (Gutenberg tự nhận heading H2/H3).
3. **Trang chủ**: tạo Page "Trang chủ" → dán file `01-trang-chu.md` → vào **Cài đặt → Đọc → Trang chủ hiển thị: A static page → chọn "Trang chủ"**.
4. Gắn ảnh đại diện (Featured image) cho từng trang từ `assets/brand/`.

## Cấu trúc menu đề xuất

- Trang chủ
- Sản phẩm (shop WooCommerce)
- Tin tức
- Đăng ký lắp đặt
- Hỗ trợ (Liên hệ)
- Giới thiệu

## Danh sách PLACEHOLDER cần thay trước khi xuất bản

| Placeholder | Thay bằng |
|---|---|
| `[HOTLINE]` | Số hotline của bạn |
| `[ZALO]` | Link Zalo OA hoặc số Zalo |
| `[EMAIL]` | Email liên hệ |
| `[ĐỊA CHỈ]` | Địa chỉ cửa hàng |
| `[TÊN CHỦ HỆ THỐNG]` | Họ tên / tên hộ kinh doanh |
| `[MST]` | Mã số thuế hộ kinh doanh |
| `[SỐ ĐĂNG KÝ WEB BÁN HÀNG]` | Số đăng ký Bộ Công Thương (xem lưu ý dưới) |

## Lưu ý pháp lý (quan trọng với web bán hàng tại Việt Nam)

- Theo Nghị định 52/2013/NĐ-CP (sửa đổi bởi NĐ 85/2021), website bán hàng **bắt buộc thông báo/đăng ký** với Bộ Công Thương tại **online.gov.vn** và hiển thị số đăng ký ở cuối trang.
- Footer phải hiển thị: tên đơn vị, địa chỉ, hotline, email, MST.
- Chính sách bảo mật phải đúng Nghị định 13/2023/NĐ-CP về bảo vệ dữ liệu cá nhân (đã viết sẵn trong file 06).
